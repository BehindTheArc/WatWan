# 와알못의 홀짝 시음기 (WatWan)

와인 셀러 관리, 시음 노트, 매장에서 쓰는 '와인 쟁여놓기'까지 담은 개인 와인 기록 웹앱입니다.

- 내 셀러: 라벨 사진(본 라벨·병목 라벨)을 붙인 와인병으로 보관 와인 관리, 보관 기간 자동 계산, 코르크 오픈 & 잔 사진
- 시음 노트: 0.5점 단위 별점, 재구매 의사, 당도·산도·타닌·바디감·점도·알코올감·여운 기록
- 와인 쟁여놓기: 마셔본 와인을 별점 순으로, 라벨 크게 보기, Vivino·Wine-Searcher·네이버 최저가 검색(한글 이름 자동 영문 변환·자동완성)
- 와인 공부: 품종 지도, 가격대별 대표 와인, 정보 소스, 기초 지식
- 더보기: 닉네임, 설정, 백업·복원, Gemini API 키 연결(선택)

## AI 기능 (선택)
더보기 → Gemini API 키에 본인의 무료 키(https://aistudio.google.com/apikey)를 넣으면 라벨 찍어서 찾기, 라벨 자동 입력, AI 영문 변환·해설을 쓸 수 있습니다. 키는 각자의 브라우저에만 저장됩니다.

기록은 사용하는 브라우저에 저장됩니다. 기기를 바꿀 때는 더보기 → 백업 파일 내보내기 / 불러오기를 이용하세요.
